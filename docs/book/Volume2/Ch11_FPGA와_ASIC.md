# Chapter 11. FPGA와 ASIC — 굳은 회로와 말랑한 회로

---

## 11.1 용어

**ASIC**
/ˈeɪsɪk/
에이식 (Application-Specific Integrated Circuit)
**특정 용도로 회로를 영구히 새겨 제조한 칩.** 노트북 CPU, 스마트폰 AP가 전부 이것.

**FPGA**
/ˌɛfpiːdʒiːˈeɪ/
에프피지에이 (Field Programmable Gate Array)
**출하 후 현장(field)에서 회로를 다시 구성(program)할 수 있는 칩.**

## 11.2 비유 — 인쇄 vs 화이트보드

```
ASIC = 인쇄된 책
  · 한 번 찍으면 못 고침
  · 대량으로 찍으면 권당 매우 쌈
  · 초판 준비(설계+마스크 제작)에 수십억 원

FPGA = 화이트보드
  · 몇 번이든 지우고 다시 그림
  · 한 장 한 장은 비쌈
  · 준비 비용은 거의 없음 (설정 파일만 부으면 됨)
```

## 11.3 역사 — 왜 만들어졌는가

1980년대, 칩 하나 만들려면 마스크(회로 원판) 제작에만 거액이 들었습니다. 소량 생산·시제품·연구용으로는 도저히 수지가 안 맞았죠. 1985년 Xilinx(자일링스, 현재 AMD에 인수됨)가 최초의 상용 FPGA XC2064를 내놓습니다. 아이디어:

> **"회로를 굳히지 말고, 설정 가능한 부품들을 깔아두고 연결만 바꾸자."**

이후 FPGA는 시제품 검증, 통신 장비, 방송, 군수, 그리고 최근에는 **AI 가속 연구**의 표준 도구가 됐습니다. **ASIC으로 굽기 전에 FPGA로 검증**하는 것이 업계 표준 흐름입니다.

## 11.4 트레이드오프 정리

| | ASIC | FPGA |
|---|---|---|
| 속도 | 빠름 (GHz대) | 상대적으로 느림 (수백 MHz대) |
| 전력 | 효율적 | 더 먹음 (설정 회로 오버헤드) |
| 단가 | 대량이면 매우 쌈 | 개당 비쌈 |
| 초기 비용 | 수십억 (마스크) | 0 (보드 값뿐) |
| 수정 | 불가능 | **몇 초 만에 재구성** |

### 왜 FPGA가 ASIC보다 느린가

같은 기능이라도 FPGA는 "범용 부품 + 설정 배선"을 거치므로 신호 경로가 깁니다. 전용 게이트를 직결한 ASIC보다 지연이 커서 클럭을 높이 못 올립니다. **유연성의 세금**이라 보면 됩니다.

## 11.5 현재 프로젝트 연결

- **Coral NPU의 원래 정체는 ASIC 설계도**입니다. RTL에 TSMC/GF 공정 매크로(`USE_TSMC12FFC` 등)가 있는 이유 — 실칩으로 구울 것을 전제한 코드예요.
- 우리는 그 설계도를 **FPGA(ZCU102)에 부어 검증**하는 표준 흐름을 밟고 있는 겁니다. "Coral을 FPGA에 올린다" = "ASIC 설계의 FPGA 프로토타이핑".
- 그래서 `SYNTHESIS` define으로 **FPGA용 경로(합성 가능한 메모리 기술)** 를 골라야 했던 것이고, `USE_GENERIC`이 벤더 중립 구현을 고르면서 **DSP 추론이 안 된** 부작용 가설도 여기서 나옵니다.
- 클럭 기대치도 조정해야 합니다: ASIC에서 GHz급을 노린 설계라도 FPGA에서는 수십~수백 MHz가 정상입니다. M4에서 타이밍이 안 나오면 그게 자연스러운 일이에요.

## 요약·퀴즈

- ASIC = 굳은 회로(빠르고 쌈-대량 전제, 수정 불가), FPGA = 재구성 회로(유연, 느리고 개당 비쌈).
- 업계 표준: FPGA로 검증 → ASIC으로 양산. 우리 프로젝트가 정확히 앞 단계.
