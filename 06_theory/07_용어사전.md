## AI / NPU

| 용어 | 뜻 |
|---|---|
| **NPU** | Neural Processing Unit. 신경망 연산 전용 처리 장치 |
| **MAC** | Multiply-Accumulate. 곱하고 누적. 딥러닝 연산의 기본 단위 |
| **추론 (Inference)** | 학습이 끝나 고정된 가중치로 답만 계산하는 단계. **이 프로젝트의 대상** |
| **학습 (Training)** | 데이터를 보며 가중치를 찾아내는 단계. 대형 GPU 서버 영역 |
| **SIMD** | Single Instruction, Multiple Data. 명령 하나로 데이터 여러 개 동시 처리 |
| **NVDLA** | NVIDIA의 오픈소스 딥러닝 가속기. **이전 프로젝트 대상 (7/15 변경)** |

## 프로세서 / 아키텍처

| 용어 | 뜻 |
|---|---|
| **ISA** | Instruction Set Architecture. CPU가 알아듣는 명령어 규격 |
| **RISC-V** | 누구나 무료로 쓸 수 있는 개방형 ISA |
| **TCM** | Tightly Coupled Memory. 코어 직결 전용 메모리. **항상 1클럭** 접근 |
| **ITCM / DTCM** | 명령어용 TCM (8KB) / 데이터용 TCM (32KB) |
| **파이프라인** | 명령을 여러 단계로 쪼개 겹쳐 처리 |
| **in-order dispatch** | 명령을 순서대로 발행 |
| **out-of-order retire** | 완료는 순서가 뒤바뀔 수 있음 |
| **크로스 컴파일** | x86 PC에서 RISC-V용 바이너리를 만드는 것 |

## FPGA / 하드웨어

| 용어 | 뜻 |
|---|---|
| **FPGA** | Field Programmable Gate Array. 회로를 다시 짤 수 있는 소자 |
| **MPSoC** | Multi-Processor System on Chip. CPU 여러 종류 + FPGA를 한 칩에 |
| **PS / PL** | Processing System(고정 CPU) / Programmable Logic(FPGA 영역) |
| **XCZU9EG** | ZCU102에 탑재된 칩. 약 600K 로직셀 |
| **LUT** | Look-Up Table. 임의 논리를 표로 흉내내는 기본 부품 |
| **FF / Register** | 플립플롭. 값 1비트 저장 |
| **BRAM** | Block RAM. FPGA 내장 메모리 블록 |
| **DSP48E2** | Xilinx FPGA의 전용 곱셈-누적 회로 |
| **BUFGCE** | 글로벌 클럭 버퍼. 클럭을 칩 전체에 분배 |
| **IOB** | Input/Output Block. 칩 외부 **물리 핀**에 연결. ZCU102는 328개 |
| **비트스트림** | FPGA에게 "이런 회로가 되어라"라고 지시하는 설정 파일 |
| **RTL** | Register Transfer Level. 레지스터 간 데이터 흐름 수준의 하드웨어 기술 |
| **추론 (inference)** | *합성 문맥*: 합성기가 코드를 보고 전용 하드웨어(BRAM 등)에 자동 매핑하는 것 |

> ⚠️ **"추론"은 두 가지 뜻**으로 쓰입니다. AI 문맥(inference = 답 계산)과 합성 문맥(inference = 자동 매핑). 헷갈리지 마세요.

## 버스 / 인터페이스

| 용어 | 뜻 |
|---|---|
| **AXI4** | ARM이 만든 칩 내부 버스 규격 |
| **manager / subordinate** | 요청하는 쪽 / 응답하는 쪽 (구 master/slave) |
| **5채널** | AW(쓰기주소) W(쓰기데이터) B(응답) AR(읽기주소) R(읽기데이터) |
| **VALID / READY** | 핸드셰이크 신호. 둘 다 1일 때 전송 성립 |
| **M_AXI_HPM0** | PS가 주도해 PL을 제어하는 포트 |
| **S_AXI_HP0** | PL이 주도해 PS 쪽 DDR에 접근하는 포트 |
| **CDC** | Clock Domain Crossing. 서로 다른 클럭 사이 신호 전달 (단일 클럭이면 불필요) |

## 툴체인

| 용어 | 뜻 |
|---|---|
| **Chisel** | Scala로 하드웨어를 기술하는 언어. **회로를 생성하는 프로그램** |
| **Verilog / SystemVerilog** | 표준 하드웨어 기술 언어. Vivado가 읽는 형식 |
| **Bazel** | 구글제 빌드 도구 |
| **bazelisk** | Bazel 버전을 자동으로 맞춰주는 실행기 |
| **Verilator** | Verilog를 C++로 번역해 PC에서 실행하는 시뮬레이터 |
| **DPI-C** | Verilog가 C 함수를 호출하는 통로. **합성 불가** |
| **WSL2** | 윈도우 안에서 리눅스를 돌리는 기능 |
| **심볼릭 링크** | 실제 파일을 가리키는 바로가기 |
| **Vivado** | FPGA 하드웨어 설계 → 비트스트림 생성 |
| **Vitis** | 소프트웨어/펌웨어 개발 (베어메탈 앱, FSBL, PMU) |
| **bootgen** | 조각들을 BOOT.bin으로 조립하는 도구 |
| **PetaLinux** | Xilinx 보드용 리눅스 빌드 도구 (이번엔 미사용) |

## 합성 / 구현

| 용어 | 뜻 |
|---|---|
| **Synthesis (합성)** | 코드 → 논리 게이트 그물망. **"자원이 충분한가"** 판정 |
| **Implementation (구현)** | 실제 LUT 배치 + 배선. **"타이밍이 맞는가"** 판정 |
| **Top module** | 회로의 최상위 모듈. 바깥 껍데기가 됨 |
| **Verilog define** | 컴파일 시점 코드 경로 스위치 (`SYNTHESIS` 등) |
| **module redefinition** | 같은 이름 모듈이 두 번 정의된 오류 |
| **타이밍 위반** | 신호가 다음 클럭 전에 도착 못 하는 현상 |
| **슬랙 (slack)** | 타이밍 여유 시간. 양수=통과, **음수=위반** |
| **임계 경로** | 가장 오래 걸리는 신호 경로. 최대 주파수를 결정 |
| **Block Design** | Vivado에서 블록을 배치·연결하는 GUI 설계 |
| **Address Editor** | Block Design에서 각 블록의 주소를 정하는 곳 |

## 부팅

| 용어 | 뜻 |
|---|---|
| **베어메탈** | OS 없이 하드웨어를 직접 제어 |
| **BootROM** | 칩에 영구 각인된 최초 부팅 코드. 수정 불가 |
| **FSBL** | First Stage Boot Loader. DDR 초기화 + 비트스트림 로딩 |
| **PMU** | Platform Management Unit. 전원·초기화 관리 |
| **ATF** | Arm Trusted Firmware. 보안 계층 (베어메탈에선 생략) |
| **U-Boot** | 2단계 부트로더 (베어메탈에선 생략) |
| **BOOT.bin** | 부팅 조각들을 묶은 컨테이너 파일 |
| **BIF** | bootgen에게 주는 **조립 설명서** |
| **`[pmufw_image]`** | BIF에서 PMU 펌웨어를 지정하는 항목. **7/14 실패 원인** |
| **.hdf / .xsa** | 하드웨어 정보 파일 (구/신 형식, 2019.2 기준 전환) |
| **xparameters.h** | Vitis가 .xsa로부터 자동 생성하는 주소 정의 헤더 |
| **디바이스 트리** | 보드 하드웨어 지도. 리눅스용 (베어메탈에선 불필요) |

## 보드 접속

| 용어 | 뜻 |
|---|---|
| **UART** | 시리얼 통신. 보드 콘솔 출력 |

| **Dropbear** | 임베디드용 경량 SSH 서버 |
